# Baptism Specification

Baptism reuses much of Communion but should feel lighter and activate fewer modules by default.

## Core structure
- Ceremony + celebration
- Two possible locations
- Guest list
- Invitations/RSVP
- Tasks
- Budget
- Menu/venue
- Payments/deposits where needed
- Day plan
- PEPA conclusions

## Event-specific data/modules
### Ceremony
- church/parish
- time
- address
- documents/tasks
- godparents

### Godparents
Store godparent names/roles as specific event data.

### Invitation scope
As in Communion:
- ceremony + celebration
- ceremony only
- celebration only

Invitation content adapts to the chosen scope.

### Restaurant/venue
Support menu, adult/child pricing, allergies, deposit, pending balance and included services.

### Optional modules
Usually off by default unless selected:
- Tables
- Guest details/favors
- Photographer/video
- Clothing/preparation
- Gifts received

## Gifts received
Same private optional model as Communion.

## Invitation styles
- soft
- elegant
- minimalist
- floral
- discreet religious
- neutral
- modern
- optional baby photo

## Day plan
Preparation -> ceremony -> photos -> travel -> celebration.
